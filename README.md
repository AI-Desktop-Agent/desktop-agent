# Desktop Agent

A modular and extensible desktop AI agent.

## Architecture

The project is designed around a modular Agent Runtime with
replaceable components for:

- Audio
- Wake-word detection
- Speech-to-text
- LLM providers
- Text-to-speech
- Tools
- Memory
- Security
- Desktop UI
